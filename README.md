# Study Lock-in

Study Lock-in is a simple study website designed to help students stay focused during study sessions. It provides a timer, background sounds, tasks, themes, and progress tracking in one place.

## Features

* Study timer with different time options
* Pause, resume, and reset timer
* Background study sounds
* Different themes
* Task list for study goals
* Progress tracking
* Motivational quotes
* Data saved using browser Local Storage
* Responsive design for different screen sizes

## Technologies Used

* HTML
* CSS
* JavaScript
* Local Storage

## Project Structure

* `index.html` - Home page
* `about.html` - About page
* `focus.html` - Main focus and study page
* `styles.css` - Website styling
* `script.js` - Website functionality
* `sounds/` - Folder for study sound files

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. The website will open in your browser.

## Audio

The website supports local audio files for background sounds.

Place the required `.mp3` files inside the `sounds` folder and make sure their filenames match the names used in the JavaScript file.

## Main Purpose

The purpose of this project is to create a simple and distraction-free environment where students can manage their study sessions, tasks, and focus time.
